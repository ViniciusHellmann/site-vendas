WEBFORGE - SITE PARA VENDA DE SITES

Arquivos:
- index.html
- style.css
- script.js

COMO USAR:
1. Coloque os 3 arquivos na mesma pasta.
2. Abra o arquivo index.html no navegador.
3. Para publicar, envie os 3 arquivos para sua hospedagem.

IMPORTANTE:
No arquivo script.js, altere:

const WHATSAPP = "5548999999999";

para o seu número real.

Formato:
55 + DDD + número

Exemplo:
const WHATSAPP = "5548999999999";

Esta versão não usa Google Fonts, localStorage, IndexedDB ou qualquer sistema externo de armazenamento.
